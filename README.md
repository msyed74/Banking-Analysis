# Banking-Analysis
Interactive Banking Analysis Dashboard built with Power BI to analyze loan performance, customer banking relationships, deposits, demographics, occupations, nationality, income bands, and advisor performance using interactive filters and visualizations.

## 📊 Dashboard Preview

![Banking Analysis Dashboard](./Banking_Analysis_Dashboard.png)

🏦 Banking Analysis Dashboard

An interactive Banking Analysis Dashboard developed in Microsoft Power BI to analyze customer banking relationships, loan performance, and key financial metrics. The dashboard transforms banking data into actionable insights through interactive visualizations, KPIs, filters, and demographic analysis.

📊 Dashboard Features
Total Loan Analysis
Bank Loan & Business Lending
Credit Card (CC) Balance Analysis
Bank Loan by Banking Relationship
Bank Loan by Occupation
Bank Loan by Income Band
Bank Loan by Nationality
Gender-wise Analysis
Institution Advisor Analysis
Interactive year/date filtering
Interactive slicers for customer segmentation
🛠️ Tools & Technologies
Microsoft Power BI
Power Query – Data cleaning and transformation
DAX – Measures and calculated metrics
Data Visualization
Business Intelligence
Data Analysis
🎯 Business Objective

The objective of this project is to provide a centralized view of banking loan performance and customer characteristics. The dashboard helps analyze how lending varies across customer segments, income levels, occupations, nationalities, banking relationships, and other demographic factors.

📈 Key KPIs
Total Loan
Bank Loan
Business Lending
Credit Card Balance
Loan distribution across customer segments
Loan distribution by income band
Loan distribution by occupation and nationality
